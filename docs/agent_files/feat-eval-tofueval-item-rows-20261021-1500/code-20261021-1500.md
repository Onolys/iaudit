Only C2 Task 6 is implemented, using the approved C2 PRD. The adapter hook is left
for Task 7; no TASKS.md files, mapping rules, gold extraction, or other modules change.

`eval/datasets/tofueval/item_rows.py` exposes
`build(item, gold, prediction, failure, mapping=None) -> ItemRow`. Rows contain the
PRD's exact common and dataset detail fields. Sentence records join by sent_idx,
retain native type names and offsets, and snapshot claim lists without source text
or explanations. Concern matches use the injected/shipped frozen mapping, including
raw Tense/Modality Error alias normalization and MeetingBank exclusions/overrides.
Recall-only and dataset-inapplicable types remain gold data without concern-match keys.

Outcomes are TP/TN/FP/FN with unresolved explicitly displayed (scored wrong by B3's
primary policy). Match is true for TP/TN, false for FP/FN, null for unresolved/failure.
A missing prediction or failure suppresses all predicted claims and produces all
unresolved sentences. An unmapped failure has status unmapped; other failures have
status failed. A normal projection, including unresolved coverage, has status ok.
No made-up factual prediction is used for failures.

Verification uses fictional, offline rows. Fifteen cases cover the worked six-sentence
counts/outcomes, exact row shape and B3 JSON schema, native offsets/types, source-text
exclusion, every confusion outcome at sentence/summary level, both unresolved gold
classes, failed and unmapped items (even with stale predictions), mapping aliases and
overrides, reordered projection sentences, immutable inputs, and detached output lists.

### Implemented task 4 pair conventions

- Type codes: Extrinsic Information `EI`, Mis-Referencing `MR`, Tense/Modality `TAM`, Stating Opinion as Fact `OF`, Contradiction `CO`, Nuanced Meaning Shift `NMS`, Reasoning Error `RE`. Every sentence has scalar boolean `type_<code>` tags; NMS and RE remain recall flags without concern-match levels.
- `concern:<code>` pairs use `gold=True`, applicable mapping types, and `concern_population` tags `gold_inconsistent` or `gold_consistent`. Inconsistent sentences participate only for their native gold types; consistent sentences provide base-rate populations. `concern_detected:<code>` is emitted only for gold-inconsistent sentences predicted inconsistent.
- Unresolved predictions use `pred=None` and `failure="unresolved"`, including item-level failures. Native sentence pairs carry `claims_mapped`, `meta_consistent_n`, and `boundary_crossing_n`. Native summary pairs carry scalar `sentences_total`, `claims_total`, `claims_unmapped`, `claims_boundary_crossing`, and `concern_not_in_mapping:<name>` diagnostics.
